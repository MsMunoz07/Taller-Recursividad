# Taller de Recursividad

Michael Stiven Muñoz Bedoya

## DescripciOn
Taller de Esructuras de Datos. Son 14 ejercicios hechos en Java y cada uno se resuelve con una funcion recrsiva. Todos los archivos están en la carpeta `src/Recursividad`.

## Ejeercicios
1. **Factorial: calcula el factorial de un número.
2. **Invertir número: invierte los dígitos de un número (123 → 321).
3. **Sumatoria de fracciones: calcula 1 + 1/2 + 1/3 + ... + 1/n.
4. **Suma de dígitos: suma los dígitos de un número (123 → 6).
5 **Sumatoria hasta n: suma todos los números desde 1 hasta n.
6 **Potencia:* calcula la base elevada al exponente.
7. **MCD:** halla el máximo común divisor de dos números con el algoritmo de Euclides.
8. **Copiar cadena:* copia una cadena de texto en otra.
9. **Cociente:** calcula la división entera usando restas sucesivas.
10. **Multiplicación:* multiplia dos números usando sumas sucesivas.
11. **Suma de un arreglo:* suma los elementos de un arreglo.
12. **Suma de una matriz:* suma los elementos de una matriz de m x n.
13. **Fibonacci:* imprime la serie de Fibonacci hasta un límite.
14. **Ackermann:* calcula el valor de la función de Ackermann para dos números.


Para ejecutar otro ejercicio solo cambiamoss el nombre de la clase al final (por ejemplo `Ejercicio07MCD`).
